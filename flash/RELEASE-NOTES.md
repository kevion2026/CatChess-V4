## 校验

训练与推理梯度有限差分；3,977 手增量 / 撤销 / 重建与状态恢复；60 个搜索窗口；4,067 个换子与 6,367 个攻击者对拍；47,415 个保留局面的整数 / 浮点评分与颜色旋转；542 个杀棋证明局面。关闭几何后的留出误差显著恶化，证明发布网络实际使用几何，但这不等于重新训练无几何模型的棋力差。

原数据 316,392 行，训练 264,894、原验证 23,706、原测试 23,709、开发验证 4,083。规范化去重、原基础分区字节和哈希均经审计；本次没有新增接受赛局面进入训练。

正式全局棋谱由独立 Python 规则回放；三次重复或 240 半回合判和，无合法着法判负。源码包在隔离目录重建，要求与受测程序逐字节相同。

## 能力边界

本次“以小博大”对照是 V3.2 单线程，64 MiB TT、863,522 参数；Flash 单线程，4 MiB TT、214,274 参数。它不等价于击败三搜索进程 V4 Pro，不承诺全面强于皮卡鱼，也没有凭空给出绝对 Elo。

开发中首个逐行点积小模型对 V3.2 的 24 局仅 39.6%；切换到稀疏整数布局后同开发开局为 60.4%。这些小批结果只用于筛选，受运行负载和抽样影响，不作为性能单变量证明。原模型、基线程序和历史发行包保持原样。

没有完整长将长捉、开局库和残局库；ARM / Linux 二进制未在本轮验证。Windows 版需 AVX2 / FMA。
